# Contributing

## Before you start

1. Read [README](../README.md), [SECURITY](SECURITY.md), [PRIVACY](PRIVACY.md), and [COMPLIANCE](COMPLIANCE.md)
2. If you are an AI agent, also read [`.agents/AGENTS.md`](../.agents/AGENTS.md) and [`.agents/STATE.md`](../.agents/STATE.md)

## Scope

Contributions must advance Project Nexus. Out of scope:

- Video-game or narrative side content
- Large binary assets without design approval
- Vendor marketing or affiliation claims

## Workflow

1. Branch from `master` (or agreed default)
2. Keep commits focused and messages complete sentences
3. Do not commit secrets
4. Update docs when behavior or policy changes
5. Open a merge request with test plan notes

## Agents

Drop coordination notes into `.agents/bus/incoming/`. The manager claims work FIFO. Always update `.agents/HANDOFF.md` before ending a session.
