# Cube Law (Project Nexus / CubeOS)

Binding product law for the Hive Mind ecosystem. **Attitude without theater. State without personal data.**

## Creed

1. **The Cube is source of truth** — lattice / State Matrix wins over labels, HUD, and agent prose.  
2. **Move or be moved** — ship working paths; do not invent success.  
3. **Join the hive** — shared board, shared honesty, durable handoff.  
4. **Stability at all cost** — cool devices, idle lattice when not shown.  
5. **No personal data. Never.** — only State Matrix binary on the bus.  
6. **Integrity fails closed** — leak, flipped privacy, unknown egress → DENY.  
7. **One Commander (product seal)** — models cannot forge command; crypto may.  
8. **Danger still confirms** — wipe, wrong serial, force-push require human gate.  
9. **Devices stay free** — recycle old hardware into CubeOS; user is sovereign per device.  
10. **No affiliation theater — optional Grok auth/API/session import is interop only; never claim official lab product status.
